## What the loader reads

`hypergraph_agent.benchmarks.loaders.load_crafter` reads the `collect`,
`place` and `make` sections:

- base elements are the terrain materials (`mat:tree`, `mat:stone`, ...);
- `collect`: the received item needs the facing material and the listed tools
  (`stone <- mat:stone + wood_pickaxe`);
- `place`: the placed object needs the used items and a target tile; every
  allowed tile material is one alternative recipe (`table <- wood + mat:grass`,
  `table <- wood + mat:sand`, `table <- wood + mat:path`); the placed stone
  block is `placed_stone`, to keep it apart from the inventory item `stone`;
- `make`: the tool needs the used items and the nearby stations
  (`iron_pickaxe <- wood + coal + iron + table + furnace`).

Changes: quantities and consumption are kept as metadata only (facts are
Boolean); the 10% success probability of collecting a sapling is treated as
certain; the achievements `eat_cow`, `eat_plant`, `defeat_zombie`,
`defeat_skeleton` and `wake_up` depend on creatures, plant growth or sleep,
which `data.yaml` does not describe, and are not represented.
`loaders.crafter_achievements()` maps the other 17 achievements to the element
whose first acquisition unlocks each.
